# VELVOX Scam Prevention — Privacy Policy

**Last updated: 17 August 2026**

VELVOX Scam Prevention is a Discord bot designed to detect scams, phishing attempts, malicious links and other potentially dangerous content.

## Data we process

To provide its security functions, the bot may process:

* Discord message content, including URLs, for scam and phishing detection.
* Discord user IDs where required for authorized notification functionality.
* Discord server/guild IDs for security-related configuration.
* Security-related configuration such as scam signatures, blocklists and authorized notification settings.

Message content is processed for the purpose of detecting threats. VELVOX does not intentionally maintain a permanent archive of users' Discord messages.

We do not intentionally collect or maintain telemetry, advertising profiles, behavioral analytics, or message-history databases.

## External services

The bot may communicate with third-party services and public data sources to perform security checks, retrieve blocklists, expand URLs, or provide security information. Those services may receive information necessary for the requested security operation and are governed by their own privacy policies.

## AI and machine learning

Message content is **not** used to train, fine-tune, or develop AI or machine-learning models.

## Data sharing

VELVOX does not sell user data or intentionally share user data for advertising or profiling purposes.

## Data security

We use reasonable measures to limit the data processed and retained by the bot. However, no system or internet service can be guaranteed to be completely secure.

## Data minimalization

The data that is collected through the intentional use of the bot is the following:
1. **Discord UserID** - Used for DM permission, if the user intentionaly allows the bot to message him/her the UserID is stored in a database. If the user later opt's out (possible at any time) the UserID is removed from our database. (By default the user is opted out.)

2. **Discord GuildID** - If a server administrator or owner wants the bot to automaticly remove flagged messags he/her can use a command to opt in or out (default is out). When they opt out the record is removed from the database.

3. **Reports** - The bot can receive reports through commands used by users. These can contain sensitive information if the user intentionaly fills those in. (We do not ask for personal or private information). Reports and records there of are removed after they has bin handled.

## Discord

VELVOX Scam Prevention operates through Discord and is subject to Discord's platform and privacy practices. VELVOX does not control data independently stored or processed by Discord.

## Changes

This policy may be updated when the bot or its data practices change.
